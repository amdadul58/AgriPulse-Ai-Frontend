🌱 AgriPulse AI — Frontend

Smart Agriculture & Crop Disease Advisor

AgriPulse AI is an AI-powered smart agriculture project designed to support farm management, crop disease detection, and agricultural recommendations through a user-friendly interface.

This repository contains the frontend application for the AgriPulse AI platform.

🚀 Features

- 📊 Dashboard for accessing agriculture-related features
- 🔐 Authentication interface
- 🚜 Farm management
- 🌾 Crop management
- 🦠 Crop disease advisory interface
- 👁️ Vision-based disease detection interface
- 🌱 Crop recommendation interface
- 🧪 Fertilizer recommendation interface
- 💬 AI Chat interface
- 📚 RAG Search interface
- 🌦️ Weather interface
- 🔗 Integration with backend APIs

Available features depend on the current implementation and backend configuration.

🛠️ Technology Stack

- React
- Vite
- JavaScript
- CSS
- ESLint
- REST API Integration

⚙️ Installation & Setup

1. Clone the Repository

git clone https://github.com/amdadul5/AgriPulse-Ai-Frontend.git
cd AgriPulse-Ai-Frontend

2. Install Dependencies

npm install

3. Start the Development Server

npm run dev

Open the local URL displayed in your terminal.

4. Build for Production

npm run build

5. Preview the Production Build

npm run preview

🔗 Backend Integration

The frontend is designed to communicate with the AgriPulse AI backend through REST APIs.

Backend Repository:
https://github.com/amdadul58/AgriPulse-Ai-Backend

API Documentation:
http://127.0.0.1:8000/docs

Start the backend separately and configure the frontend API base URL to match your backend environment.

Do not publish API keys, database passwords, authentication secrets, or private environment configuration.
